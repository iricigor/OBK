Get started on Windows

Install OBK, sign in to your school, and keep your children's Komens messages available on your PC. Windows 10 or later is required.

Install the app

  1. Open the official latest release.
  2. Download OBK-<version>-windows-x64-setup.exe and run the installer.
  3. Start OBK from the Start menu. Administrator rights and a separate .NET installation are not normally required.

Windows may show an unknown-publisher warning. Current Windows releases are unsigned while code-signing enrollment is pending. Download only from the official Releases page and check its published checksums and signing status before approving installation.

Sign in and download

  1. Search for your child's school, or enter its Bakaláři address.
  2. Enter your Komens username and password. Optionally name the child and choose to remember the password for future refreshes.
  3. After Login successful, wait for messages to finish downloading.
  4. When attachments start, choose Download attachments in background to enter the reader, or wait for them to finish. Progress and download details remain at the bottom of the reader.

Keep OBK open while downloads continue. Only completed files are available offline. If your school does not allow mobile API access, OBK may be unable to sign in.

Read and refresh

Choose a child or All children in the sidebar, then choose Inbox, Noticeboard, Sent, or Excuses. Select a message to read it; use search, sorting, and grouping to find older messages.

Refresh downloads new content for the selected child or all children in the current scope. To always update every child, turn on Settings > Refresh > Always refresh all children.

OBK is read-only. Sending a reply, excuse, or confirmation still requires Bakaláři. Opening a message here does not mark it read on the school's server.

Already using Android?

To avoid typing a saved Windows password on your phone, open Settings > Accounts > Transfer to Android in Windows OBK and choose Scan from PC on Android.

The encrypted QR transfer works offline. Follow the three-word confirmation while the transfer window is open. See the Android start guide for installation, or the transfer documentation for details.

Updates and help

OBK checks for updates while it runs and offers Update and restart when a newer version is ready.

For a problem report, create a GitHub issue with the Windows version, OBK version, and reproduction steps. Do not include passwords, private messages, or personal school data.
