Get started on Android

Read Komens messages on your phone, including when you are offline. The Android app is a preview and requires Android 10 or later.

Install the preview

  1. On your phone, open the official latest release.
  2. Download OBK-<version>-android.apk and open it.
  3. If Android asks, allow installation from that browser or file manager for this installation. Review the warning and confirm installation.

Install only a package you trust. Android preview APKs use development signing, not a trusted public app-store identity. Android may block them or show an unknown-app warning. Do not grant installation access to untrusted sources.

Sign in to your school

  1. Search for your child's school, or enter its Bakaláři address.
  2. Enter your Komens username and password. Optionally name the child and save the password for future refreshes.
  3. After Login successful, wait for messages to finish downloading.
  4. When attachments start, choose Download attachments in background to enter the reader, or wait until they finish.

Keep OBK open while files download. Android suspending the app can interrupt a download; pending files are not available offline.

Or scan a saved account from Windows

If you already use OBK on a PC, open Settings > Accounts > Transfer to Android on Windows and choose Scan from PC on the phone. Follow the encrypted QR transfer and three-word confirmation while the Windows transfer window is open.

See the Windows start guide or transfer documentation. No cloud account synchronization is involved.

Read and refresh

Use the navigation menu to choose a child or All children and browse Inbox, Noticeboard, Sent, or Excuses. Tap a message to read it and use the search field to find downloaded content.

Refresh updates the selected child or all children in the current scope. Settings > Refresh > Always refresh all children can override that choice.

Optional hourly checks and notifications can be enabled in Settings > Scheduled checks. Notification permission is requested when you enable notifications, not at first sign-in.

OBK cannot send replies, excuses, or confirmations, and does not mark messages read on the school server. Use Bakaláři for those actions.

Update without losing your archive

Install a newer compatible release over the existing app. OBK's updater verifies checksum, package, version, and signing compatibility before opening Android's installer.

Do not uninstall an existing app just to update it: uninstalling deletes its local archive and encryption key. A workflow preview signed with a different key may not update the installed app. Read the Android installation and signing notes before switching packages.

Need help?

Create a GitHub issue with the Android version, OBK version, and reproduction steps. Never include passwords, private messages, or screenshots containing personal school data.
